# 阶段 3 方案：人脉、新闻发布会、社交媒体

> 状态：待批准（2026-11-21）。依据：对 FM27 代码的调查（下文「FM 里已有的」）。

## 核心：这个世界会主动找你

FM 的发布会、谈话、新闻都是固定套路，而且总是你去点它们。这一阶段反过来：**每个游戏日，世界里的人会因为真实发生的事主动联系你**——球员、教练组、主席、对手主教练、经纪人、旧识、记者、球迷。你可以回、可以不回、可以吵起来，每一次互动都会被记住，并在人和人之间传开。

```
FM 的真实状态 ──► 故事引擎 ──► 谁会因此找你 / 记者问什么 / 谁发帖
（比赛、训练、伤病、     （每天挑出有新闻价值的事）
 合同、转会、情绪……）            │
                               ▼
                私聊 · 来电提醒 · 发布会 · 社交媒体 · 采访
                               │
                               ▼
               记忆、关系、八卦、舆论（再影响下一天）
```

## 一、人脉（通讯录扩展）

| 圈子 | 是谁（来自 FM） | 会因为什么主动找你 |
| --- | --- | --- |
| 球员 | 一线队、青年队、外租球员 | 上场时间、状态、伤病、生活、替队友说话（阶段 2 已开始） |
| 教练组 | 球队职员名单（助教、体能、球探……） | 训练报告、某人状态下滑、想推荐球员、对你的安排有意见 |
| 俱乐部高层 | 俱乐部的主席、董事、体育总监 | 战绩压力、预算、转会意见、合同、「下课」风声 |
| 对手 | 下一场对手的主教练、德比对手 | 赛前心理战、赛后握手或互呛、借你的球员 |
| 经纪人 | 球员的经纪人、你自己的经纪人 | 给客户要合同、兜售球员、透露别的俱乐部对你有兴趣 |
| 旧识 | 你执教过的球员和共事过的人、球员「偏爱的人」里的熟人 | 叙旧、求建议、想来投奔你、告诉你圈内消息 |
| 想要的人 | 你的转会目标、职员空缺的候选人 | 回应你的接触、讨价还价、犹豫 |
| 记者 | 跑你俱乐部线的记者（FM 里记者是完整人物，带所属媒体） | 求证传闻、约专访、发布会后追问 |

- 每个人按身份说话：主席关心钱和成绩，经纪人只关心客户，对手主教练话里带刺。
- 每个人都有对你的关系、记忆和设定档（同阶段 2）。
- 谁会主动联系你、多频繁，由「有没有真事 + 关系 + 性格 + 身份」决定；每天总量有上限，热闹程度可调。

## 二、新闻发布会（重点）

**什么时候：** 赛前、赛后，以及大事之后（重要转会、连败、球员公开不满）。FM 自己安排发布会时同步出现（数据里能看到「赛前新闻发布会即将开始」）。

**谁来：** 3–5 名真实记者，来自不同媒体。每个记者有立场和风格（亲俱乐部的本地记者、专挖丑闻的小报、数据派），并记得和你的过往——你上次骂过他，他这次会更刁难。

**问什么：** 故事引擎从真实状态里挑最刁钻的角度：

- 最近的战绩和状态、下一场对手、伤病名单；
- 训练和更衣室：不开心的球员、谁抱怨上场时间、更衣室小圈子；
- 转会传闻（FM 的传闻带媒体来源）、合同纠纷；
- 球员在社交媒体上发的东西、接受的采访；
- 你自己说过的话（「你上周说会给年轻人机会，为什么万祥还是没上场？」）；
- 董事会期望、球迷情绪。

**怎么答：** 自由打字。记者会追问、挑刺、断章取义；你可以讲道理、打太极、拒绝回答、反呛，甚至提前离场。

**后果：**

- 你的话被提炼成标题和引语，进入新闻和社交媒体；
- 被你点名的球员（夸或批评）会有反应，并在更衣室传开；
- 对手主教练会回应；董事会、球迷的看法随之变化；
- 言辞过激有被足协调查、罚款的风险（引擎模拟）。

## 三、社交媒体

面板里的动态页，像真实的社交 App：

- **谁在发：** 球迷（按 FM 的球迷群体分：死忠、普通球迷……）、记者、评论员、你的球员、别队球员、对手球迷。FM27 的新闻自带「社交反应」，作为种子。
- **发什么：** 比赛、转会、你的发布会发言、球员表现、更衣室传闻。
- **你能做什么：** 点赞、回复、发帖、私信；可以和球迷对线。吵架会发酵：截图疯传、记者引用、球员看到。
- **球员公开发声：** 不开心又敢说的球员（看 FM 的性格和「媒体应对」）会发意味深长的帖子、点赞批评你的内容，或接受采访；这会变成发布会问题和更衣室八卦。

## 四、点开任何人

- 聊天、发布会、动态里出现的名字和头像都能点。
- 点开是人物卡：头像、身份、所属、和你的关系、他记得的事、「发消息」；
- 「在 FM 中打开」：用 FM 自己的跳转机制打开他的资料页（FM 里有 `PersonReferenceClickedHandler` 等，需要先做一个技术验证；不通就只显示人物卡）。
- 模型写的文字里提到的人，由引擎标记成可点的链接（只标记真实存在的人）。

## 五、故事引擎（所有功能共用）

- 每个游戏日扫描 FM 的状态和我们自己的世界事件，生成「新闻点」，每个带分量：
  - 比赛（比分、进球、失误、评分、全场最佳）、训练评分、伤病、合同、转会传闻、奖项；
  - 情绪变化（新出现的不满）、更衣室变化、你的言行；
- 分量高的新闻点决定：谁会找你、记者问什么、谁发帖、谁接受采访、什么会成为八卦。
- 事实（比分、名字、日期、评分）只来自 FM 和引擎；模型负责语气和台词。

## 分步

建议先把阶段 2 的记忆做完（所有东西都靠它），然后按下面的顺序：

| 步 | 内容 | 完成标准 |
| --- | --- | --- |
| 2f | 记忆和关系，含比赛、训练记忆 | 他记得你们聊过的、比赛里发生的 |
| 3a | 故事引擎 | 每个游戏日列出有分量的新闻点，全部有 FM 依据 |
| 3b | 主动联系 + 人脉扩展 | 每天有人因为真事主动找你；通讯录有教练组、高层、对手、经纪人、旧识、记者 |
| 3c | 人物卡和点击跳转 | 点任何名字看到人物卡；能跳到 FM 的资料页（技术验证通过的话） |
| 3d | 新闻发布会 | 赛前赛后自动出现，记者按真实状况刁难，你的话变成新闻并有后果 |
| 3e | 社交媒体 | 动态页、发帖回复对线、球员公开发声和采访 |
| 2g–2i | 八卦、生活层、更衣室动态 | 复用故事引擎，接着做 |

## 风险

| 风险 | 应对 |
| --- | --- |
| 消息太多变成骚扰 | 每天上限、热闹程度设置、只在有真事时联系 |
| 模型编造事实 | 新闻点和事实都由引擎给出，模型只写语气 |
| 调用模型的花费 | 只在需要时生成；动态里的大量球迷帖批量生成、长度短 |
| 跳转 FM 资料页不稳定 | 先做技术验证；失败就只用我们的人物卡 |
