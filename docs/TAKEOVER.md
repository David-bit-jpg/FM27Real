# 原版交互和手机双向同步

> 状态：方向已确认（2026-11-21，第二次修订）。

FM 里和人打交道的地方——球员谈话、队内训话、新闻发布会、合同谈判、董事会会议、关键时刻、通道采访——保留原版的界面和选项。手机（我们的面板）是另一条渠道。两条渠道**双向同步**，并且**都不能出错**：

1. **原版 → 世界记忆**：在原版里说的话和对方的反应，全世界都记得，和手机上聊的一样。
2. **手机 → FM 的真实效果**：手机上的对话和原版一样，真的改变士气、满意度和更衣室动态。

## 一、原版 → 世界记忆

每一次原版交互都同步进我们的世界：

- 你选了哪个话题、说了哪句话、对方怎么回应（回话、肢体语言、情绪变化）；
- 写进对方的记忆和你们的聊天记录（标注为「FM 谈话」），并相应调整我们的关系分；
- 公开场合（发布会、采访、训话）的内容进入新闻、社交媒体和更衣室八卦。

这样，你之后在面板里和他自由聊天时，他记得「上周教练当面表扬了我那场的扑救」；发布会上你说过的话，记者和球员也都记得。自由聊天是在原版之外多出来的一条渠道，两边共用同一份记忆。

## 两类交互

| 类型 | FM 原版 | 同步到 |
| --- | --- | --- |
| **私下**（一对一） | 球员谈话、合同谈判、经纪人谈判、董事会会议、职员会议、一对一的关键时刻 | 对方的记忆 + 你们的聊天记录 + 关系分 |
| **公开**（有观众或会被记录） | 新闻发布会、通道采访、赛前赛后媒体、队内训话 | 在场每个人的记忆 + 新闻标题和社交媒体 + 更衣室八卦 |

## 原理

1. **识别**：桥从数据通道看到 FM 打开了某个交互（谈话、发布会、训话……）。
2. **读取**：交互过程中读出话题、你选的那句、对方的回应、肢体语言和情绪；交互结束时整理成一条记录。
3. **同步**：引擎把记录写进记忆（分量按内容决定：承诺、批评、表扬分量高）、聊天记录和关系分；公开交互再交给故事引擎，变成新闻、帖子和八卦。

原版交互本身由 FM 照常结算，我们不改它。

## 二、手机 → FM 的真实效果

手机上聊完，引擎判断这次对话相当于 FM 的哪种原版交互（表扬表现、警告、处理不满、做出承诺、批评训练态度……），再**用 FM 自己的正常途径**提交这个交互，让 FM 按原版规则计算士气、满意度、承诺和更衣室影响。

- 只在 FM 当时确实允许这种交互时提交（同一类谈话的冷却、对象是否合适，由 FM 判断）；
- 一次手机对话最多对应一次原版交互，避免刷士气；
- 提交失败或找不到对应的交互时，**跳过回写**，对话照常进行，游戏不受任何影响；
- 回写的结果（FM 给出的反应）再写回记忆，保证两边一致。
