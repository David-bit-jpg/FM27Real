# 接管原版交互：把所有选项换成你自己的话

> 状态：方向已确认（2026-11-21），技术验证待做。

FM 里有大量和人打交道的地方——和球员谈话、队内训话、新闻发布会、合同谈判、董事会会议、关键时刻——全都是固定选项。FM27Real 把它们全部换成**自由输入**：可以先选一个大概方向，但说出口的话永远由你自己写，对方用自己的话回应你。

## 两类交互

| 类型 | FM 原版（只有选项） | 换成 |
| --- | --- | --- |
| **私下**（一对一） | 球员谈话（表扬、警告、处理不满、承诺）、合同谈判、经纪人谈判、董事会会议、职员会议、一对一的关键时刻（`PivotalMoment`） | 聊天界面：对方按自己的性格和处境回话，可以来回多轮 |
| **公开**（有观众或会被记录） | 新闻发布会（`PressConferenceEditSession`）、通道采访（`TunnelInterview`）、赛前赛后媒体、队内训话（`TeamTalk`，对全队）、公开声明 | 发布会 / 更衣室界面：几名记者或全队在场，你的话会成为标题、或在更衣室里传开；训话后每个球员各有反应 |

## 原理：FM 自己算后果

为了让心态、满意度、承诺这些**真的在 FM 里改变**，又不去直接改内存：

1. **识别**：桥从数据通道看到 FM 打开了某个交互（谈话、发布会、训话……），读出 FM 提供的选项（题目、每个选项的文字和语气类别）。
2. **接管界面**：我们的面板弹出，显示情境、对方是谁、从 FM 选项归纳出的几个**大概方向**（例如安抚 / 施压 / 表扬 / 批评 / 回避），以及输入框。
3. **你说你的话**：自由输入；也可以点一个方向作为起点再改。
4. **映射并提交给 FM**：引擎让模型判断你的话最接近 FM 的哪个选项（含语气），然后**用 FM 界面自己的方式提交**这个选项。FM 按原版规则计算士气、幸福度、承诺、关系等后果。
5. **用 FM 的反应说话**：读出 FM 给出的结果（对方的肢体语言、反应、士气变化），模型据此让对方用自然的话回应你——FM 决定结果，模型负责把它说出来。
6. **我们这一层**：同时写入记忆、关系、八卦、新闻（发布会的话进标题和社交媒体，训话的话在更衣室传开）。

找不到合适的映射时，面板列出 FM 原版选项让你确认，不会乱提交。

## 技术验证（先做）

需要在游戏里逐个抓取协议：

1. FM 打开交互时的数据通道（目标类型、选项列表的属性）；
2. 你点选项时 FM 界面发出的动作（`PerformChannelActions` / `UpdateChannelData` / `SendEvent`）；
3. 用同样的动作从我们这边提交，确认 FM 正常结算。

顺序：球员谈话 → 队内训话 → 新闻发布会 → 合同和经纪人谈判 → 董事会、关键时刻、通道采访。

## 放进计划

- 球员谈话的接管和阶段 2 的私聊合并：同一个聊天界面，FM 原版谈话触发时自动带上 FM 的结算。
- 新闻发布会、通道采访、训话的接管并入阶段 3 的发布会和更衣室设计。
- 合同、经纪人、董事会的接管放在阶段 3 之后。
