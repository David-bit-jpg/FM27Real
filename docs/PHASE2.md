# 阶段 2 方案：游戏内界面 + 世界引擎 + Claude

> 状态：已批准（2026-11-21）。2a、2b 完成。

## 目标（这一阶段做完是什么样）

在 FM27 里打开任意球员的资料页，页面上出现一个「私聊」按钮。点一下，**游戏窗口里**滑出一个聊天面板：左上角是 FM 自己的头像，球员按他的性格、处境、和你的过往说话。关掉游戏、第二天（游戏日）再找他，他还记得你们聊过什么。

只做这一条完整的路，把三层都打通。发布会、社交媒体、博彩放到阶段 3、4，复用这一阶段的全部基础。

## 架构

```
┌──────────────────── FM27 游戏进程 ────────────────────┐
│ 桥 libfm27real.dylib                                  │
│  · 查询接口（阶段 1 已有）                              │
│  · 新增：当前页面识别（正在看哪个球员）                    │
│  · 新增：游戏窗口里的面板（WKWebView），按钮 + 快捷键       │
└──────────────┬───────────────────────────▲────────────┘
               │ 游戏数据                     │ 面板加载界面
┌──────────────▼───────────────────────────┴────────────┐
│ 世界引擎（独立本机进程，127.0.0.1，令牌）                 │
│  · 每个存档一个 SQLite：人物快照、关系、记忆、对话          │
│  · 规则：一次对话之后关系怎么变（确定、可复现）              │
│  · 模型 API 层：统一接口；测试用 Claude                   │
│  · 提供面板的网页和接口                                   │
└───────────────────────────────────────────────────────┘
```

### 1. 游戏内面板（桥）

- 用 macOS 的 WKWebView 叠在游戏窗口内部，不是另开窗口：跟着游戏窗口移动、全屏，切出游戏时一起隐藏。
- 两个入口：
  - **上下文按钮**：桥从数据通道知道你正在看哪个球员，资料页右上角出现 FM 风格的「私聊」按钮；
  - **快捷键**（例如 ⌘J）：打开「主教练手机」主页（消息列表）。
- 面板内容是网页（HTML/CSS），由世界引擎提供。界面风格贴近 FM：深色、FM 字体字号、头像和队徽用 FM 图包。
- 不改 FM 自己的界面元素（UI Toolkit），也就不会随 FM 界面更新而坏。

先做一个小验证：在游戏窗口里显示一个网页面板、能打字、不影响游戏操作。这一步不通过就退回「独立窗口贴在游戏旁边」的方案，其余部分不受影响。

### 2. 世界引擎

- **Python 写**（标准库 + SQLite，不装额外依赖），开发迭代最快；以后需要再打包成 App。
- **存档识别**：用存档名 + 主教练 UID + 开档日期，每个存档一个数据库，不同生涯互不串。
- **人物快照**：按需从桥读取（姓名、年龄、位置、性格、上场时间感受、合同状态、生涯简介……），带游戏日期缓存。
- **记忆**：每次对话后，模型写一段第三人称摘要（「主教练答应下周让他首发」），连同游戏日期存进记忆；下次对话把相关记忆放进上下文。
- **关系**：每个人物对主教练有几项分值（信任、好感、尊重），范围和变化幅度由规则限定。模型只能「提议」变化，由引擎校验、限幅后生效。
- 阶段 2 **不写回游戏**，关系只存在我们自己的数据库里。写回 FM（士气、幸福度）是阶段 5，全部在存档副本上测试。

### 3. 模型 API 层

- 统一接口：输入「人物资料 + 关系 + 记忆 + 当前情境 + 对话」，输出「回复文字 + 结构化意图」（情绪、关系变化提议、承诺、是否想结束对话）。
- **测试后端：Claude，用你这个账号**，通过本机 Claude Code 命令行无界面调用（不开任何工具，只生成文字）。需要你在终端登录一次。
- 以后可加 Anthropic API（官方 SDK）等后端，在设置里切换，规则层不变。
- 人物台词用中文，口吻按性格和情境走（「平衡」的门将和「暴躁」的前锋说话不一样）。

## 风险

| 风险 | 应对 |
| --- | --- |
| 网页面板和 Unity 抢键盘输入 | 2a 先验证；不行就用独立小窗口贴在游戏旁边 |
| 模型回复慢（几秒） | 面板显示「对方正在输入」；回复流式显示 |
| 对话消耗 Claude 账号额度 | 只在你发消息时调用；上下文控制在必要范围 |
| 模型乱编游戏事实 | 只给它桥读出的真实数据；事实性内容（比分、合同）由引擎填，不让模型编 |
