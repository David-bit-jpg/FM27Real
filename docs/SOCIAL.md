# 更衣室、八卦与生活层方案

> 状态：待批准（2026-11-21）。数据来自对 FM27 代码和一个真实生涯（莱斯特城，2028-03-07）的实测。

## 二、设计

原则和阶段 2 一致：**世界引擎决定发生什么，Claude 只负责把话说出来。**

内容分两类，规则不同：

| 类别 | 例子 | 规则 |
| --- | --- | --- |
| **事实** | 上场时间、伤病、合同、比赛、转会传闻、训练评分、兄弟查理 | 必须和 FM 一致，由引擎从桥读出后提供 |
| **生活色彩** | 周末带狗去公园、更衣室里谁的音乐最难听、训练后和阿尔维斯打赌输了请吃饭 | 可以编，但不能和事实矛盾；**一旦说出口就成为这个世界的设定**，存进引擎，以后所有人都按它来 |

### 1. 社交网络（每个游戏日从 FM 刷新）

- 节点：一线队球员和主要职员。
- 连线：同一社交圈、偏爱关系（兄弟 > 好友/队友 > 前队友）、地位（领袖说话传得远）。
- 加上我们自己的数据：每个球员对你的信任/好感/尊重（阶段 2 的关系分）、他记得的对话。

### 2. 话题从哪来（只用真实发生的事）

- FM 的状态：幸福度顾虑（「对队内处境心存顾虑」）、不开心的球员、上场时间、伤病、合同、转会传闻、新援、比赛结果。
- 你的行为：私聊里说的话、做的承诺、（阶段 3 起）发布会和社交媒体发言。
- 变化：某人连续被放上替补、某人在训练里被批评、某人刚续约。

### 3. 传播（引擎规则，可复现）

每个游戏日，每条话题沿社交网络扩散：

- 好友、兄弟、同圈子：大概率传到；
- 球队领袖知道后会传遍自己的圈子；
- 圈外的人（例如那 3 个独行者）很少听到，也很少传；
- 每多传一手，内容可能走样（引擎记「准确度」，例如「教练可能卖萨姆」变成「教练已经决定卖萨姆」）；
- 每个球员记住「从谁那儿听到了什么」。

### 4. 你在游戏里看到什么

- **私聊会带上他听到的东西。** 他只知道传到他耳朵里的事：「听说你跟萨姆说他下个月会多打几场？」——前提是这话真的传到了他那儿。
- **更衣室动态**（面板里的新页面）：短场景，例如训练后几个人的闲聊、小圈子的群聊片段、更衣室里的争执。以「助理教练/队长透露」或「你无意间听到」的方式出现，保持真实感。
- **助理教练简报**：「苏塔那几个人对轮换有些想法」「塞特福德好像担心自己的位置」。

### 5. 主动找你聊天

球员不只是等你找他。引擎每个游戏日决定谁会主动发消息给你，以及为什么：

| 触发 | 例子 |
| --- | --- |
| 他自己的处境 | 「教练，能聊聊我最近的位置吗？」（幸福度出现顾虑时） |
| 训练 | 「今天加练任意球，进了 8 个！」（训练评分高）/「膝盖有点紧，明天想轻一点」（体能、伤病风险） |
| 比赛前后 | 首发后的感谢、被换下后的不服、进球后的兴奋 |
| 生活 | 生日（FM 有出生日期）、家人来看球、找房子、学英语（外籍新援、语言数据）、小爱好 |
| 社交 | 替好友说话：「萨姆最近状态挺好的，您考虑一下？」；新援入队时老队员拉他进群 |
| 关系 | 关系越近，越会聊和足球无关的日常；关系差的人只在有事时才找你 |

- 发不发、发多少由性格和地位决定：外向、领袖型的人更爱说话；独行者很少主动找你。
- 每天总量有上限，避免刷屏；可以在设置里调「热闹程度」。
- 你可以回、可以晾着；晾太久本身也会影响关系。

### 6. 出身与文化

每个人的国籍、出生地、语言让他的话题和说话方式不一样：

| 依据 | 怎么用 |
| --- | --- |
| 出生城市和地区 | 家乡的天气、吃的、家人朋友；想家；比赛去到离家近的地方；「老乡」之间更亲近 |
| 语言熟练度 | 英语基础的人（万祥、勒奥）发消息短、简单、偶尔夹母语词，可能请会同一种语言的队友帮忙；同语言的球员私下用母语聊（更衣室动态里标注） |
| 偏爱的俱乐部 | 对阵儿时支持的球队时激动；回归传闻；和支持对手球队的队友斗嘴（塞特福德和阿贾克斯） |
| 国家队 | 入选或落选、国际比赛日、队内不同国家的球员在国家队比赛前后互相调侃 |
| 节日和日历 | 按国籍的重要节日和习俗（万祥的春节、大森翔的新年、雅各布森的圣诞），用「想家、家人视频」这类个人化的方式出现 |
| 海外生活 | 时差、家人在国外、找房子、适应天气和饮食，新援尤其明显 |

**避免刻板印象：** 性格和行为由 FM 的性格数据决定，出身只提供话题和背景，不把人写成国籍标签；不从国籍推断宗教等数据里没有的东西。

### 7. 生活设定（让世界前后一致）

- 每个人有一份「设定档」：FM 的事实（国籍、出生地、语言、家人、生日、偏爱的俱乐部、生涯）＋ 聊天中逐渐长出来的生活细节（宠物、爱好、口头禅、和谁不对付）。
- 新细节由模型在对话里提出，引擎检查不和事实冲突后记入设定档；之后这个人和其他人提到时都要一致（塞特福德说过他养了只叫 Max 的狗，阿尔维斯以后也会知道 Max）。
- 生活色彩可以在八卦里传播，和事实一样走社交网络。

### 8. 后果

- 话题会改变我们自己的关系分：例如你对一个人的承诺没兑现，他的好友对你的信任也下降。
- 小圈子有共同情绪：领袖不满时，整个圈子对你的看法会往下走。
- 写回 FM（士气、幸福度）仍在阶段 5，优先用 FM 自己的动作（开队会、赞扬、和不开心的球员谈话），而不是直接改内存。

## 三、放进计划的位置

阶段 2 的私聊直接用上社交数据（成本低、效果大），八卦传播和更衣室动态在私聊打通后紧接着做：

| 步 | 内容 |
| --- | --- |
| 2c | 世界引擎骨架：存档识别、SQLite、人物快照**含社交数据**（圈子、地位、好友、顾虑、对你的看法） |
| 2d | 模型层 + Claude：人物对话的上下文包括他的社交处境 |
| 2e | 聊天面板：**每个球员单独的聊天记录**（修正现在共用一份的问题） |
| 2f | 记忆和关系分 |
| 2g（新增） | 八卦传播：话题从真实状态生成，沿社交网络扩散；私聊里人物会提到他听到的事 |
| 2h（新增） | 主动消息和生活层：每个游戏日有人主动找你（训练、生活、处境、替朋友说话）；出身与文化；生活设定档 |
| 2i（新增） | 更衣室动态和助理教练简报；面板里的未读提示和游戏内消息弹出 |

## 四、风险

| 风险 | 应对 |
| --- | --- |
| 八卦太多变成噪音 | 每天话题数有上限，只挑真正有变化的事 |
| 模型编造没发生的事 | 事实类内容只来自引擎；生活色彩允许创作，但先经引擎检查不和事实冲突，再写进设定档 |
| 主动消息太频繁 | 每天上限 + 「热闹程度」设置；没有新鲜事的人不发 |
| 某些社交字段在别的存档里含义不同 | 已在莱斯特城对照过；换存档时先跑 `dressing-room` 检查 |
